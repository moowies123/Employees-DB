Transaction Log Backup
الـ Transaction Log Backup هو نوع من أنواع النسخ الاحتياطي في SQL Server، لكن بدل ما ياخد نسخة من قاعدة البيانات كلها هو بياخد نسخة من كل العمليات اللي حصلت على قاعدة البيانات من آخر Log Backup

بمعنى أبسط أي عملية حصلت زي
insert 
update
delete
بتتسجل الأول في ملف اسمه Transaction Log
ولما أعمل Log Backup، SQL Server بيحفظ العمليات دي في ملف Backup
الميزة هنا إني لو حصل Crash للسيرفر أقدر أرجع قاعدة البيانات لآخر لحظة قبل المشكلة ومش هفقد بيانات كتير
SQL Server Agent Job

الـ Job هو عبارة عن مهمة بتشتغل أوتوماتيك في SQL Server
يعني بدل ما كل يوم أدخل أعمل Backup بإيدي، أقدر أقول لـ SQL Server
كل يوم الساعة 12 بالليل اعمل Backup لوحدك

الفرق بينهم 
Transaction Log Backup: بيحفظ العمليات اللي حصلت الى قاعدة البيانات علشان أقدر أسترجع البيانات لو حصل مشكلة
SQL Server Agent Job: بيشغل أي مهمة بشكل تلقائي في وقت معين أو حسب جدول زمني
